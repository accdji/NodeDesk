# 轻量级工作流编排器 — 产品功能设计 & 开发进度

> 最后更新: 2026-06-03

## 设计原则

- **轻量**：个人/小团队工具，非企业平台
- **页面少而精**：5 个页面覆盖完整工作流
- **操作可逆**：删除需确认，关键操作有记录
- **信息分层**：概览页看全貌，详情页看细节

---

## 导航结构

```
侧边栏:
├── 项目列表  /projects       ← 一级入口（含项目看板/工作流编辑/实时监控）
└── 执行历史  /history        ← 一级入口（含历史列表/执行详情）

页面流转:
  项目看板 → 点「详情」→ 工作流编辑器
  项目看板 → 点「执行」→ 实时监控 → 执行详情
  工作流编辑器 → 点「执行」→ 实时监控
  执行历史 → 点「查看详情」→ 执行详情
```
